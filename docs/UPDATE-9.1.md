# f8-plugin 9.1 — лучи, вращение звёзд, пластинки и подзорная труба

Продолжение версии 9.0, **Paper 1.21.11 / Java 21**. Существующие чары,
созвездия, награды и прогресс не сбрасываются.

## Как обновить

1. Остановите свой сервер, замените старый JAR на `target/adaptation-9.1.jar`
   из артефакта сборки. Не оставляйте две версии в `plugins/`.
2. **Обновите ресурспак `f8resurs-resourcepack.zip` и нажмите `F3 + T`.**
   Лучам теперь нужны новые модели и текстуры; старый пакет для 9.0 их не содержит.
   Если пакет раздаёт сервер, обновите URL/хеш раздаваемого ZIP.
3. Сохраните свои PNG: существующие картинки предметов и звёзд не менялись.
   При использовании своего пакета добавьте из нового ZIP файлы
   `star_beam` и `star_beam_preview` в `assets/f8resurs/items/`,
   `assets/f8resurs/models/item/` и `assets/f8resurs/textures/item/`.
4. Папку данных, `blocks.yml`, `playerdata.yml` и файлы созвездий не удаляйте.
   Старый `config.yml` подходит; отсутствующие новые настройки берутся по умолчанию.

## Лучи

- Вместо растянутого стержня Энда используется плоская прямоугольная полоса:
  без утолщённого основания, боковых граней и сужающегося профиля.
- Отключены тени display-сущностей, затенение граней и ambient occlusion модели;
  яркость постоянная. Шейдер-паки клиента могут добавлять собственные эффекты.
- Вся полоса размещена за сферой звёзд, а не только её концы. Направления на
  концы сохраняются, поэтому полоса подходит к звёздам сзади и не закрывает их.
- Прежнее значение `line-thickness` сохранено: это масштаб, соответствующий
  ширине основной части старого стержня (2/16 блока).

## Вращение звёзд

Вращается только картинка вокруг собственной оси, не её положение на небе.
Поворот камеры, прицеливание и движение вместе с игроком работают как в 9.0.
Поворот плавно интерполируется клиентом.

```yaml
constellations:
  star-rotation-degrees-per-second: 4.0
```

По умолчанию один оборот занимает 90 игровых секунд. `0` останавливает вращение,
отрицательное значение меняет направление. После изменения — `/stars reload`.

## Подзорная труба и предварительный луч

- При промахе нет сообщений в actionbar: трубу можно использовать для обычного
  осмотра, не перекрывая компас/HUD. Незавершённый выбор при промахе сбрасывается тихо.
- При первом выборе звезды: **«Звезда выбрана.»**
- Предварительный луч **пунктирный**: между штрихами настоящая прозрачность.
- Превью можно направлять к любой видимой звезде, в том числе другого созвездия.
  Наличие и вид превью не зависят от правильности соединения.
- Проверка созвездия и разрешённых связей выполняется только при втором клике.
  Настоящие соединения разных созвездий по-прежнему не сохраняются.
- На один предварительный луч нужна одна display-сущность, а не отдельная сущность
  для каждого штриха. Обычные завершённые линии остаются сплошными.

## Медный нотный блок

- Удалён неполный список пластинок и приблизительных длительностей. Песня,
  звук и длительность берутся из настоящего компонента `jukebox_playable` предмета.
  Поддерживаются все ванильные пластинки 1.21.11, включая **Tears** и **Lava Chicken**;
  учитывается также зарегистрированная песня, назначенная предмету датапаком.
- Замена песни определяется по её ключу, даже если Material предмета не изменился.
- **Shift + ПКМ не открывает меню**, позволяет поставить блок на медный нотный блок
  или использовать предмет. Ванильная перенастройка ноты заблокирована обеими руками,
  чтобы не потерять маркер и медную текстуру. Обычный ПКМ по-прежнему открывает меню.
- Редстоун, частицы раз в секунду, пауза/повтор с начала и защита от поршней сохранены.

## Проверки без игрового сервера

```sh
python3 scripts/build_resourcepack.py --check
mvn --batch-mode clean verify
```

Unit-тесты проверяют неподвижный центр вращающейся звезды, направления концов луча,
равномерную ширину и глубину всей полосы, наведение между созвездиями без фильтра
по рёбрам и перевод длительности песни в тики. Проверка ресурспака дополнительно
проверяет плоские незатенённые модели, сплошную/пунктирную прозрачность и соответствие ZIP.
Сервер Minecraft/Paper для проверки не запускается.

### Быстрая проверка у владельца сервера

- Обновить пакет, ночью проверить постоянный луч и превью: нет серых боков/основания,
  звёзды перед лучами; со временем картинка звезды поворачивается вокруг своего центра.
- Выбрать звезду, навести на звезду того же и другого созвездия без клика:
  в обоих случаях один и тот же пунктир. Клик по другой группе не создаёт связь.
- Посмотреть трубой мимо звёзд (в том числе в шахте): никаких сообщений при промахе.
- Проиграть Tears, Lava Chicken и несколько старых пластинок; проверить снятие питания,
  возврат сигнала и замену пластинки.
- Shift + ПКМ блоком в основной и дополнительной руке: блок ставится, меню не открывается.
  Проверить также пустые руки: медная текстура не должна пропадать.

Компиляция и unit-тесты не заменяют визуальную проверку на настоящем клиенте.
