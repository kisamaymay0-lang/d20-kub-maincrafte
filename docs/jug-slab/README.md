# Кувшин без щелей: плита-носитель в ресурспаке

Это файл для **ресурспака** — без него поставленный кувшин будет выглядеть как
обычная дубовая плита (в версии 10.11 плагин ставит кувшин на техническую
плиту петрифайд-дуба, а модель для неё выбирает пак).

## Что было не так

Кувшин стоял как нот-блок. Нот-блок — **сплошной** блок, а Minecraft не рисует
грани соседних блоков, прижатые к сплошному блоку (оптимизация, «block
culling»). У модели кувшина по краям есть зазор в 1 пиксель, через него и было
видно «вырезанную» грань пола, стены или потолка — те самые щели.

## Как починили

Блок-носитель заменён на **техническую плиту петрифайд-дуба**: она не является
сплошным блоком, поэтому соседние блоки рядом с кувшином рисуются как обычно —
щелей нет ни в полу, ни в стенах, ни в потолке. Состояние плиты выбирает
модель:

* `type=bottom` (нижняя плита) — пустой кувшин, модель `f8resurs:block/ancient_jug`;
* `type=top` (верхняя плита) — налитый кувшин, модель `f8resurs:block/ancient_jug_filled`;
* `type=double` — оставлена ванильная модель: двойная плита сплошная, для
  кувшина она не используется.

## Как применить

1. Возьмите файл `petrified_oak_slab.json` из этой папки.
2. Положите его в свой ресурспак по адресу:
   `assets/minecraft/blockstates/petrified_oak_slab.json`
3. Пересоберите ZIP (`python3 scripts/build_resourcepack.py`), обновите
   `resource-pack-sha1` у сервера и перезайдите в игру.

Больше в паке менять ничего не нужно:

* `assets/minecraft/blockstates/note_block.json` можно оставить как есть —
  кейсы кувшина в нём больше не используются (плагин такие блоки сам
  переносит на плиту), медные кейсы нужны, вреда от лишних строк нет;
* модели `ancient_jug.json` / `ancient_jug_filled.json` остаются на месте —
  теперь их использует плита, а не нот-блок;
* папку `docs/jug-model-fix/` (плита-подставка) можно больше не применять —
  она лечила симптом, а не причину.

## Проверка

Поставьте кувшин на пол, прислоните к стене и поставьте блок сверху: вокруг
кувшина не должно быть ни одной «дырки» — под ним видно пол, за ним стену,
над ним потолок.

## Если хочется иначе

* Пустой и налитый кувшин можно поменять местами (нижняя плита — налитый):
  скажите, поменяю местами константы в плагине.
* Плита петрифайд-дуба даёт полублок-коллизию: на пустой кувшин можно
  «заступить» (как на ступеньку). Если это мешает — есть вариант вернуть
  обычный нот-блок и жить со щелями, но тогда вернутся и «прозрачные» блоки
  рядом.
