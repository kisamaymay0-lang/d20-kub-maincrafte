# Косметика профиля: что нужно в ресурспаке

Косметика — это предмет, который **визуально** надет на голову игрока.
Он не занимает слот шлема, не мешает надеть настоящий шлем, не виден в слотах
брони и не выпадает при смерти: плагин держит у головы игрока отдельную
сущность-отображение (`ItemDisplay` с трансформацией `HEAD`).

## Куда плагин смотрит в паке

Модель задаётся полем `file` в `plugins/f8-plugin/cosmetics.yml`. Значению
`file: kosmetika1` отвечает **определение предмета**:

```
assets/f8resurs/items/kosmetika1.json
assets/f8resurs/items/kosmetika2.json
assets/f8resurs/items/kosmetika3.json
```

то есть ровно там же, где лежат `pref1.json … pref10.json` у префиксов.
Файл указывает на модель, например:

```json
{
  "model": {
    "type": "minecraft:model",
    "model": "f8resurs:item/kosmetika1"
  }
}
```

Саму модель (`assets/f8resurs/models/item/kosmetika1.json` или
`…/models/block/kosmetika1.json`) плагин не трогает — она ваша.

## Как это надето

* База предмета — обычный лист бумаги, у которого `item_model` заменён на
  `f8resurs:kosmetikaN`. Без ресурспака игрок увидит лист бумаги на голове
  у другого игрока.
* Высота — уровень глаз игрока, поэтому при приседании и плавании косметика
  остаётся на голове.
* Поворот берётся с игрока (наклон не используется).
* **Владелец свою косметику не видит**: в первом лице она висела бы прямо
  перед камерой. В меню `/profile` она показывается как обычный предмет.

## Меню

`/profile` → **«Настроить косметику»** (незерская звезда, слот 9). Внутри во
втором ряду две кнопки:

| Слот | Кнопка |
|---|---|
| 11 | Настроить префикс |
| 13 | Настроить косметику |

«Настроить косметику» ведёт в список косметики; там же, в слоте 13, лежит
**кейс косметики** — он вскрывается ровно как кейс префиксов (те же 9 мест,
те же «поломки», тот же салют).

Команды администратора:

```
/profile case cosmetic give <игрок>       — выдать кейс косметики
/profile cosmetic give <игрок> <номер|all> — выдать косметику
/profile cosmetic take <игрок> <номер|all> — забрать косметику
/profile cosmetic list <игрок>             — что есть у игрока
/profile cosmetic reload                   — перечитать cosmetics.yml
```

Номер — это порядок записей в `cosmetics.yml` (первая запись — №1).
