# Обновление 37 — Названия и описания напитков шейкера

## 1. Почему напитки назывались «Бутылочка воды»

Название ставилось только компонентом `item_name` (`meta.itemName(...)` + `meta.displayName(null)`).
Для зелья с `potion_contents = water` этого не хватает: клиент строит заголовок из компонента
зелья и показывает ванильное «Бутылочка воды». Предметы, у которых имя видно всегда —
«Бутылочка горячей воды» и «Пиратский ром» — ставили имя **двумя** способами.

Теперь напитки делают так же: `item_name` **и** `custom_name`. `item_name` остаётся ради того,
чтобы у предметов в рамках не появлялась плавающая подпись.

## 2. Названия (все золотые)

| id | Название | Описание |
|---|---|---|
| `mead` | `Медовуха?` | Безалькогольная медовуха, может стоит добавить в нее пиво?... |
| `matcha_tea` | `Матча-чай` | Чай с бархатистым вкусом, дающий легкую бодрость и яркость ума. |
| `daiquiri` | `Дайкири?` | Безалкогольный дайкири, может стоит в него добавить белое вино?... |
| `iced_latte` | `Айс-Латте` | Прохладный кофейный напиток с кубиками льда... освежает! |
| `murk` | `Муть` | Какая-то болотная жижа, может стоит попробовать другие ингридиенты?) |
| `pirate_rum` | `Пиратский ром` | своя подсказка про выдержку в бочке, не менялась |

Цвета зелья и модели не менялись: `0xEBAF28` / `medovuha`, `0x78A83C` / `matcha-chai`,
`0xF0466E` / `daikiri`, `0xE8C499` / `iced_latte`, `0x4E9331` / без модели у «Мути».

## 3. Подсказка в стиле пиратского рома

```
---------------------------------      тире во всю длину текста (GRAY, без курсива)
• Прохладный кофейный напиток...       маркер • , белый текст
---------------------------------      те же тире
Добавки:                               сразу, без пустой строки
• Лёд                                  зелёный / красный
```

- Разделитель — `-`, длина считается по самому длинному тексту подсказки
  (описание или строка добавки), верхние и нижние тире всегда одинаковые.
- Маркер: `•` у обычных описаний, `▶` там, где текст предлагает что-то добавить
  (медовуха и дайкири).
- В этих двух описаниях фраза «может стоит добавить в нее / в него добавить»
  жёлтая, а сам напиток («пиво», «белое вино») жёлтый и подчёркнутый.
- Тексты правятся в одном месте: `Shaker.descriptionParts(...)`, названия — в
  `Shaker.getDrinkName(...)`.

## 4. Пиратский ром — только бочка

Ром по-прежнему помечен ключом напитка (`adaptation:shaker_drink_type = pirate_rum`),
поэтому его узнаёт кувшин и подсказки, но:

- в шейкер его положить нельзя (`isAllowedIngredient` возвращает `false`);
- в подсказке шейкера он подписан «Пиратский ром», а не «Муть».

## 5. Медовуха: звук питья

`consumable` (анимация питья + `item.honey_bottle.drink`) теперь ставится **после**
`setItemMeta`, иначе мета затирала компонент.

## 6. Тесты

`ShakerTest`: точные названия и описания всех пяти напитков, три строки шапки
(разделитель / описание / разделитель), цвета и отсутствие курсива, отсутствие
лишних строк без добавок, `pirate_rum` без описания из шейкера.
