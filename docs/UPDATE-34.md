# Обновление 34 — Новая система напитков, добавок, описание Шейкера, Древний кувшин и скрытие названий в рамках

## 1. Базовые рецепты напитков для Шейкера
Базовые рецепты создают чистые напитки без базовых эффектов зелий:

1. **Медовуха** (`f8resurs:medovuha`):
   - База: `Медовые соты` + `Бутылочка горячей воды`
   - Положительные добавки: `Сахар`
   - Отрицательные добавки: любые другие ингредиенты.
   - Звук питья: `Sound.ITEM_HONEY_BOTTLE_DRINK` (звук питья бутылочки мёда).

2. **Дайкири** (`f8resurs:daikiri`):
   - База: `Сладкие ягоды` + `Сахар` + `Бутылочка обычной воды`
   - Положительные добавки: `Любой лёд`, `Сладкие ягоды`
   - Отрицательные добавки: любые другие ингредиенты.

3. **Айс-латте** (`f8resurs:iced_latte`):
   - База: `Какао-бобы` + `Любой лёд` + `Ведро молока`
   - Положительные добавки: `Бутылочка мёда`, `Любой лёд`
   - Отрицательные добавки: любые другие ингредиенты.

4. **Матча-чай** (`f8resurs:matcha-chai`):
   - База: `Зелёный краситель` + `Бутылочка горячей воды`
   - Положительные добавки: `Бутылочка мёда`, `Ведро молока`, `Любой лёд`
   - Отрицательные добавки: любые другие ингредиенты.

## 2. Механика добавок
- Все дополнительные ингредиенты, положенные в шейкер сверх базы, становятся добавками.
- **Отображение в подсказке (lore):**
  - По умолчанию выводится строчка: `[` (серый) + `SHIFT` (белый) + `] для просмотра добавок` (серый).
  - При зажатии `SHIFT` после строчки с шифтом раскрывается список добавок:
    `• Ингредиент` (светло-зелёный для положительных, светло-красный для отрицательных).
- **Эффекты:**
  - Положительные добавки в тестовом режиме не накладывают эффектов зелий.
  - Отрицательные добавки накладывают:
    - `1 плохая добавка`: Тошнота I (10 сек).
    - `2 плохих добавки`: Тошнота II (10 сек) + Отравление I (10 сек).
    - `3+ плохих добавок`: Тошнота II (10 сек) + Отравление II (10 сек).

## 3. Описание и звуки Шейкера
- **Пустой шейкер:** отображает строку `Содержимое (0/5):` серым цветом.
- **Шейкер с предметами:** отображает строку `Содержимое (X/5):` и список предметов `• Название` (белым цветом на русском языке).
- Полностью удалены надписи `(открыт)`, `(закрыт)` и подсказки.
- **Звук при попытке положить предмет в закрытый шейкер:** проигрывается звук нотного блока баса (`Sound.BLOCK_NOTE_BLOCK_BASS`).

---

## 4. Скрытие названий напитков в рамке (ItemFrame)
- У напитков, шейкера и бутылочки горячей воды название задаётся через компонент `item_name` (`meta.itemName(...)`) без `displayName` (`custom_name`), благодаря чему:
  - Напитки сохраняют свои имена в инвентаре, сундуках, хотбаре и чате.
  - При помещении в рамку над рамкой **не отображается парящая голограмма / имя предмета**.

---

## 5. Древний кувшин (Ancient Jug)
- **Поддержка кастомных напитков:** в древний кувшин можно наливать все напитки из шейкера и бутылочки горячей воды, забирать их пустой бутылочкой, а также пить напрямую из кувшина с получением эффектов (включая звук питья мёда для медовухи).
- **Падение кувшина с головы:** если игрок надел кувшин на голову и поворачивает камеру слишком высоко (вверх, pitch $\le -50^\circ$) или слишком низко (вниз, pitch $\ge 50^\circ$), кувшин соскальзывает с головы и выпадает предметом со звуком наполнения бутылочки водой (`Sound.ITEM_BOTTLE_FILL`).
