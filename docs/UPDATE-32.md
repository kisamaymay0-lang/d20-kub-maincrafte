# Обновление: АПВШ (аппарат для создания и наполнения сигарет)

Кастомный блок CraftEngine **АПВШ**, механика наполнения сигарет порохом, взрыв при затягивании и выдача в `/f8`.

## 1. Кастомный блок CraftEngine — АПВШ

- **Идентификатор блока:** `f8resurs:apvsh`.
- **Конфиг для пака CraftEngine:** [`docs/craftengine-blocks/apvsh.yml`](craftengine-blocks/apvsh.yml).
- **Модель и текстура:** `f8resurs:block/copper_note_block` (`copper_note_block.json`), сплошной куб (`solid`), проводящий редстоун.
- **Хранение данных:** инвентари блоков сохраняются в `plugins/f8-plugin/apvsh.yml` через `BatchedYamlFile`. При поломке блока выпадает предмет блока АПВШ и всё его содержимое.

## 2. Меню блока АПВШ (3 ряда по 9 слотов)

Инвентарь содержит 27 слотов:
- **1-й ряд (слоты 0..8):** забит серыми стеклянными панелями, с которыми нельзя взаимодействовать.
- **3-й ряд (слоты 18..26):** забит серыми стеклянными панелями, с которыми нельзя взаимодействовать.
- **2-й ряд (слоты 9..17):**
  - **Слоты 1, 7, 9 ряда (индексы 9, 15, 17):** заблокированы серыми стеклянными панелями;
  - **Слоты 2..6 ряда (индексы 10..14):** 5 слотов для наполнения — пока что принимают только порох (стеками до 64 шт.);
  - **Слот 8 ряда (индекс 16):** слот для наполняемого предмета — принимает только обычную бумагу в количестве ровно 1 шт. После сборки в нём появляется готовая сигарета.

Поддерживаются удобный шифт-клик (порох автоматически распределяется по 5 слотам наполнения, бумага встаёт в 16 слот) и защита от перетаскивания посторонних предметов.

## 3. Сборка сигарет по редстоуну

1. Игрок кладёт начинку (порох) в 5 слотов наполнения и 1 бумагу в слот предмета.
2. При подаче редстоун-сигнала на блок АПВШ:
   - бумага и весь порох из слотов наполнения расходуются;
   - проигрывается звук удара наковальни (`BLOCK_ANVIL_USE`);
   - на месте бумаги (слот 16) появляется готовая сигарета.
3. **Модель сигареты** зависит от суммарного количества пороха:
   - **1..8 пороха:** маленькая модель (`sigareta-small`, запас 16 палочек);
   - **9..20 пороха:** обычная модель (`sigareta`, запас 32 палочки);
   - **21+ пороха:** большая модель (`sigareta-big`, запас 64 палочки).
4. У любой сигареты остаётся белое название **«Сигарета»** без описания, состав начинки визуально скрыт.

## 4. Свойства пороха при курении

- При каждой затяжке горящей сигаретой:
  - у рта игрока появляется **1 партикл взрыва динамита** (`Particle.EXPLOSION`);
  - проигрывается звук взрыва;
  - игроку наносится урон в размере **0.5 сердца (1.0 HP) за каждую 1 штуку пороха** в сигарете (например, 10 пороха нанесут ровно 5 сердец урона).

## 5. Команда `/f8`

- В меню `/f8` в разделе **«Новые блоки»** добавлена кнопка **«АПВШ»**.
- Также блок можно получить напрямую командой `/f8 apvsh`.
