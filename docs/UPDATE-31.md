# f8-plugin 10.32 — полив меди и кораллов, паки префиксов, /f8 reload

Дополнение к [10.31](UPDATE-30.md), поверх порта [10.30](UPDATE-29.md) для Purpur/Paper 26.2 + Java 25.

## Шифт + ПКМ бутылкой с водой

* **Медь.** Работает с любой медной ступенью и с медными блоками любых устанавливаемых форм (блок, срез, ступень, плита, решётка, лампа, дверь и т.п.). Исправлена ошибка с самой первой ступенью: реальное имя второй стадии — `exposed_copper`, а не `exposed_copper_block`. `copper_block → exposed_copper → weathered_copper → oxidized_copper`. Вощёная медь сначала теряет воск, следующим поливом стареет. На полностью окисленной меди без воска дальше менять нечего — вода не расходуется. Кастомный медный нотный блок CraftEngine не подменяется, чтобы не сломать модель и музыку. Состояние блока (поворот, вода, открытость) сохраняется, показываются частицы `WAX_OFF`.
* **Кораллы.** Полив живого коралла оставляет его цветным даже вне воды. Полив мёртвого коралла (`dead_*_coral`, `_block`, `_fan`, `_wall_fan`) возвращает его живой цвет, с сохранением состояния (поворот веера и пр.). Живой коралл больше не сохнет: таймера нет, защита снимается только после разрушения блока. Координаты защищённых блоков сохраняются в `plugins/f8-plugin/corals.yml`.
* **Бутылка больше не выпивается от шифт + ПКМ по блоку.** При жесте полива использование предмета запрещается и дополнительно отменяется возможное отложенное событие выпивания; обычным ПКМ без шифта воду можно пить как прежде. В выживании успешный полив меняет одну бутылку воды на пустую; в креативе не тратит воду. Если поливать нечего, вода остаётся в руке. Работа обеими руками поддерживается.

## Паки префиксов без дублирования

Папка: `plugins/f8-plugin/prefixpacks/`, отдельный файл на каждый пак. В файле пака — **только файлы** иконок из `plugins/f8-plugin/prefixes.yml`; имя, цвет, номер и технический id каждого префикса определяются **только** в `prefixes.yml`. Пример поставляемого `pref-pack1.yml`:

```yaml
name: 'Тестовый пак'
time-hours: -1
prefixes:
  - pref1
  - pref2
  - pref3
  - pref9
```

`time-hours` — срок **кейса** с момента выдачи, `-1` — бессрочно. Выигранный префикс постоянный. Если файл в паке отсутствует в `prefixes.yml`, при перезагрузке выводится ошибка — неверный пак не заменяет работающий каталог. Старые записи вида `- name: ...; file: pref1; color: ...` принимаются: учитывается только `file`, остальные значения игнорируются. При первом обращении к профилю старые выигрыши 10.31 с id `<пак>_<file>` переводятся на общий id из `prefixes.yml` с сохранением надетого префикса.

В меню **«Префиксы»** сундучки паков находятся в середине, случайные префиксы — сверху и снизу. Нажатие на сундучок открывает **содержимое пака**: префиксы сверху и снизу (можно надеть уже полученные), в середине кнопка **«Крутить кейс»**, слева **«Отмена»** для возврата к пакам. Кейсы из разных паков не дублируют один и тот же выигрыш. Команда выдачи — `/profile case pack give <ник> pref-pack1 1`.

Обе команды `/profile prefix reload` и **`/f8 reload`** перечитывают `prefixes.yml` **и** все файлы паков; `/f8 reload` также обновляет `config.yml` и остальные настройки. Изменения имён/цветов применяются к табу, никнеймам и карточкам профиля без перезагрузки сервера. Если в файлах ошибка, старые префиксы остаются активны, а команда сообщает причину.

**Важно:** старый `plugins/f8-plugin/prefixpacks/pref-pack1.yml` не перезаписывается при обновлении плагина. Его можно оставить как есть (записи с `file` читаются) или переписать на короткий формат выше.

## Проверка на сервере

1. В выживании шифт + ПКМ по **обычному** `copper_block`: сразу появляется `exposed_copper`, частицы, в руке пустая бутылка. Повторить для `cut_copper`, плиты, ступени, двери, вощёной меди и обеих рук. На полностью окисленной меди вода не должна исчезать и **не должна выпиваться**.
2. Шифт + ПКМ водой по `dead_brain_coral_block`, `dead_fire_coral_fan`, `dead_tube_coral_wall_fan`: цвет возвращается; вне воды после нескольких минут остаётся живым; после разрушения и повторной установки снова может сохнуть.
3. Изменить `prefixes.yml` (например, имя `pref1`), выполнить `/f8 reload`: название в паке, меню и карточках обновится. Ошибочное имя файла в паке должно показать ошибку и сохранить старое состояние.
4. Открыть меню паков, нажать на сундучок: содержимое сверху и снизу, кнопка «Крутить кейс» посередине, «Отмена» возвращает к пакам. Выигрыш из пака не дублируется в списке префиксов.

CI собирает плагин и запускает unit-тесты. Игровую проверку необходимо провести на живом Purpur 26.2 + Java 25 + CraftEngine 26.8.x: сервер недоступен в этой среде.
