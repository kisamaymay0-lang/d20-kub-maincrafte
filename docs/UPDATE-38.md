# Обновление 38 — Меню напитков в /f8

## Что добавилось

`/f8` → **Новые предметы** → кнопка **«Напитки»** (слот 47, зелье с подписью
«Все напитки плагина»). По нажатию открывается отдельное меню «Напитки» на 54 слота:
фон, шесть напитков в ряд и «Назад» в центр нижнего ряда.

| Слот | Напиток | Что выдаётся |
|---|---|---|
| 19 | `drink_mead` | `Shaker.createDrinkItem(mead)` — «Медовуха?» |
| 20 | `drink_matcha_tea` | «Матча-чай» |
| 21 | `drink_daiquiri` | «Дайкири?» |
| 22 | `drink_iced_latte` | «Айс-Латте» |
| 23 | `drink_murk` | «Муть» |
| 24 | `drink_pirate_rum` | `BambooBarrel.createPirateRum()` — «Пиратский ром» |

В меню лежат **настоящие** предметы: то же название, то же описание между тире, та же
модель и те же эффекты. Метка меню (`f8_menu`) ставится только копии для витрины, а
игроку выдаётся чистый предмет — иначе шейкер не узнал бы напиток.

## Навигация

- «Напитки» открывается из меню предметов, кнопка «Назад» внутри возвращает в
  «Новые предметы» (id `back_items`), а не в главное меню.
- Меню закрывается на клик по напитку: предмет падает в инвентарь, лишнее — под ноги.
- Перетаскивание и клики по фону отменяются, право по-прежнему `f8.admin`.

## Тесты

`ProfileIconsTest.drinkMenuListsEveryDrink` — в `DRINK_CATALOG` ровно шесть напитков в
заданном порядке, id совпадают с `Shaker.RECIPE_*`.
