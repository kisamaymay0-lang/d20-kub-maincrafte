# f8-plugin 9.3 — инертное небо, профили и медали

Paper 1.21.11 / Java 21. Продолжение 9.2, без изменения урона, чаров, рецептов,
редстоуна, пластинок и существующих наград созвездий.

## Установка

1. Штатно остановить свой сервер; заменить старый JAR на `target/adaptation-9.3.jar`.
2. Обновить `f8resurs-resourcepack.zip` у клиентов/на серверном хостинге ресурспака.
   Если сервер использует SHA-1 пакета — обновить и его. На клиенте перезагрузить пакеты (`F3 + T`).
3. Не удалять данные и старый конфиг плагина. Новые параметры имеют значения по умолчанию.

Старые PNG звёзд, предметов и медного блока не менялись. В свой вариант пакета
нужно добавить девять файлов `medal_copper`, `medal_silver`, `medal_gold`:
по JSON в `assets/f8resurs/items/` и `assets/f8resurs/models/item/`,
по PNG в `assets/f8resurs/textures/item/`. Без них логика профиля работает,
но вместо рисунков медалей будут обычные самородки.

## Небо больше не повторяет прыжок

В 9.2 прогноз скорости переносил сферу почти вслед за глазами, в том числе по Y.
В 9.3 прогноз убран:

- Привязка использует положение тела и обычную высоту глаз, игнорируя позу камеры.
  Приседание не опускает сферу.
- Есть зона покоя для небольших перемещений. Во время обычного короткого прыжка
  высота сферы не меняется. Длительный полёт, падение и подъём всё-таки переносят небо.
- При длительной ходьбе точка сферы догоняет игрока плавно, с ограниченным отрывом.
  Поэтому до звёзд нельзя добежать. При большом телепорте остаётся проявление на новом месте.
- Так как глаза больше не обязаны совпадать с центром сферы, проекция лучей учитывает
  фактическое смещение наблюдателя: концы не должны отрываться от картинок звёзд.
  Пересчёт только при смещении, не чаще 5 раз/сек; поворот головы его не вызывает.
- Вращение, плавное появление/уход, пунктир и сброс выбора трубы сохранены.

Это имитация дальнего неба обычными display-сущностями, не клиентский мод космоса.
Идеальную неподвижность картинки при любом пинге/TPS гарантировать нельзя;
визуальную оценку нужно сделать на клиенте владельца.

## `/profile`

Открывает свой профиль — обычный сундук 3×9. Стиль: серые панели, золотистые
заголовки, настоящая голова игрока и пиксельные медали.

```
[медаль][медаль][медаль][медаль][медаль][медаль][медаль][медаль][медаль]
[  ·  ][  ·  ][  ·  ][ лайк ][голова][дизлайк][  ·  ][  ·  ][настройка]
[медаль][медаль][медаль][медаль][медаль][медаль][медаль][медаль][медаль]
```

### Голова и описание

- По центру второго ряда — голова со скином владельца. Название — его ник.
- В описании предмета — описание игрока, затем лайки и дизлайки.
- По умолчанию: **«Нет описания.»**
- Нажать на свою голову, написать новое описание в чат. До 160 Unicode-символов.
  Этот ввод отменяется как обычное сообщение чата и обрабатывается на основном
  потоке сервера, без асинхронных изменений инвентарей/Bukkit-объектов.
- `отмена` (или `/profile cancel`) отменяет ввод; `-` возвращает описание по умолчанию.
  На ввод отведено 2 минуты. Строки форматирования и управляющие символы не выполняются.

### Чужие профили и оценки

**Shift + ПКМ по игроку** открывает его профиль. В нём нельзя менять описание
или медали. По уточнению владельца исключение — две кнопки оценок:

- Слева от головы: зелёный краситель **«+ Поставить лайк.»**
- Справа: красный краситель **«+ Поставить дизлайк.»**
- От одного UUID одна оценка на профиль. Другая оценка заменяет первую,
  повторное нажатие текущей снимает её. Самооценка запрещена.
- Счётчики обновляются в уже открытых профилях. Оценки и медали привязаны
  к UUID, а не к отображаемому имени.

Открытие по игроку уважает отмены других плагинов, видимость и невидимость.
Дублирующиеся события interact/interact-at не открывают два окна подряд.

## Медали — три экрана

1. В правом слоте второго ряда профиля — золотая медаль **«Настроить медали»**.
2. Нажатие открывает коллекцию: все собственные медали в верхнем и нижнем рядах,
   голова **«Отмена.»** по центру возвращает в профиль. При количестве больше 18
   появляются страницы (стрелки в среднем ряду). Размещённые медали отмечены в подсказке.
3. Нажатие на медаль открывает выбор места: все 18 мест верхнего/нижнего ряда
   становятся белыми стеклянными панелями. Подсказка показывает, что будет заменено.
   Нажатие на панель размещает медаль и возвращает в профиль.
   Голова **«Отмена.»** возвращает в коллекцию без изменения размещения.

Одна медаль не занимает несколько мест. Перенос очищает её прежний слот,
а заменённая медаль остаётся в коллекции. **Shift + клик по размещённой медали
в коллекции** снимает её с профиля. Закрытие меню без подтверждения ничего не меняет.
Иконки нельзя вытащить через shift, цифры, drag, двойной или creative-клик.

У медали — название, заслуги с пустой строкой между ними, а **самая нижняя строка** —
серая дата получения. Медали профиля не являются физическими предметами для передачи.

### Автоматическая медная

Только после **нового завершения созвездия в 9.3+** выдаётся одна медная медаль
с заслугой «Собрано 1 созвездие.». Старые записи `completed` не дают ретроактивную
награду — это выбранный владельцем вариант. Игрок со старым прогрессом получает
медаль при следующем новом завершении. Дальнейшие завершения не создают копий.

Право и время получения фиксируются вместе с новым завершением в `playerdata.yml`.
Если запись профиля не удалась, медаль можно восстановить по этому маркеру после
устранения ошибки. Сброс прогресса созвездий не отнимает уже выданные медали.
Медаль сначала появляется в коллекции; владелец сам выбирает место на витрине.
Автоматических серебряных/золотых наград пока нет.

### Команда администратора

Право: `profiles.admin` либо существующее `f8.admin` (по умолчанию OP).

```
/profile medal give <игрок или UUID> <copper|silver|gold> <название> | <заслуга 1> | <заслуга 2>
```

Примеры:

```
/profile medal give Steve copper Медная медаль | Помог построить город
/profile medal give Steve silver Серебряная медаль | Исследовал север | Помог новичкам
/profile medal give Steve gold Золотая медаль | Победил на турнире
```

Можно вручную создавать все три металла, как уточнено владельцем. Дата — реальная
дата выдачи. Имя офлайн-игрока должно быть в локальном кэше сервера; иначе укажите UUID.
Название до 48 символов; 1–8 заслуг, каждая до 120 символов.

## Быстрая карточка

Зажать Shift и смотреть на игрока в пределах 8 блоков: рядом с ним быстро
проявляется небольшая карточка — ник, описание и обе оценки. Она видна только
смотрящему. Не открывает инвентарь, не затирает actionbar/компас и не создаёт
реальных пассажиров или коллизий. Стены, vanish, невидимость и уход игрока учитываются.
Отпустить Shift/отвести взгляд — карточка плавно исчезает.

```yaml
profiles:
  quick-card-distance: 8.0
  date-time-zone: system
```

`system` — часовой пояс машины сервера; можно указать, например, `UTC`.
Время игрового мира на даты медалей не влияет. Эти настройки читаются при запуске.

## Сохранение и нагрузка

- Профили: `plugins/f8-plugin/profiles/<UUID>.yml`. Пишется небольшой изменившийся
  профиль, а не база всех игроков. Используется общий последовательный атомарный
  писатель 9.2. Пакетная запись — обычно раз в секунду, с завершением при штатном выключении.
- Оценки, описание, коллекция, UUID медалей, даты и размещение сохраняются.
  Повреждённый профиль не подменяется пустым: ошибка попадает в лог, исходный файл
  остаётся нетронутым. После восстановления файла нужен перезапуск плагина/сервера.
- У офлайн-профилей ограниченный LRU-кэш. Онлайн-данные удерживаются, незаписанные
  изменения не вытесняются. Не выполняется сетевой поиск имён или скинов в цикле UI.
- Карточка: один TextDisplay на смотрящего, только при зажатом Shift; луч поиска
  5 раз/сек, текст меняется только при изменении данных/цели. Постоянные параметры
  полностью проявившейся карточки не отправляются заново каждый тик.
- Лайк обновляет голову/счётчики, не пересобирает все рисунки медалей.
- Как у пакетного сохранения 9.2, аварийное завершение до записи может потерять
  последние обычные изменения. Используйте штатную остановку и резервные копии.

Реальный TPS/MSPT не измерялся: Minecraft/Paper-сервер для проверки не создавался.
Компиляция и unit-тесты выполняются в GitHub Actions; визуальное поведение остаётся
для проверки на клиенте владельца.

## Чек-лист в игре

- Ночью попрыгать/поприседать на месте, затем побежать, подняться по лестнице,
  полетать и телепортироваться. Проверить попадание трубой и концы лучей.
- `/profile`: ровно 27 слотов, голова по центру, описание через чат не публикуется
  в общий чат. Проверить отмену, лимит, сброс через `-`, перезаход.
- Вторым аккаунтом открыть Shift + ПКМ: редактирование запрещено, оценки работают,
  повторная снимается, лайк ↔ дизлайк не удваивает счётчики.
- Завершить новое созвездие: одна медная в коллекции. Перезапустить сервер:
  даты, оценки и медали сохранены; следующая победа не дублирует медную.
- Выдать три вида вручную, разместить, перенести, заменить, отменить выбор, снять
  медаль и проверить страницы после 18 штук. Попробовать вытащить иконки из GUI.
- При Shift + взгляде карточка видна только смотрящему; за стеной/у невидимого
  игрока не появляется. Проверить снятие Shift, смену мира и выход игрока.
