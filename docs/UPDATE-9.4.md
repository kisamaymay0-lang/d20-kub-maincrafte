# F8 9.4 — медали и минималистичные карточки

Paper 1.21.11 / Java 21. Ресурспак 9.3 подходит без изменений.
Замените только JAR на `target/adaptation-9.4.jar` после штатной остановки сервера.
Перед обновлением сделайте резервную копию папки данных. Не удаляйте старые профили.

## Где теперь медали

```
plugins/f8-plugin/
  medals/
    config.yml
    players/
      <UUID>.yml
  profiles/
    <UUID>.yml
    legacy-backup/
      <UUID>.yml
```

* `medals/config.yml` — названия типов, цвета градиентов, сообщения и стандартная
  награда «Астрономия!».
* `medals/players/<UUID>.yml` — реально выданные медали конкретного игрока. Можно
  менять особое название/заслуги/металл или удалить запись, чтобы изъять медаль.
* `profiles/<UUID>.yml` — описание, оценки, места в витрине и история выдачи/объявлений.
  Обычные лайки и изменение описания **не переписывают файл медалей**.

### Перенос из 9.3

При первом чтении старого профиля сохраняется его исходная копия в
`profiles/legacy-backup/`. Сначала записывается отдельный файл медалей, и только
после этого профиль переходит на формат v2. UUID медалей, даты, оценки и места
сохраняются. Старые медали не объявляются как новые. Стандартная медная награда
за созвездие получает особое название **«Астрономия!»**.

Не возвращайте JAR 9.3 поверх новых данных без восстановления резервной копии:
старый код не знает формат профиля v2.

## Правки во время игры

После изменения YAML выполните:

```
/profile medal reload
```

Перезапуск сервера не нужен. Сначала проверяются настройки и все файлы медалей;
при ошибке действующее состояние не заменяется частично. Открытые профили и
карточки обновляются. Если выбранную для размещения медаль забрали, меню вернётся
к коллекции.

Для добавления записи проще использовать команду — она сама создаст UUID и дату:

```
/profile medal give Steve copper Астрономия! | Собрано 1 созвездие.
/profile medal give Steve silver Исследователь | Изучен север | Найден древний город
/profile medal give Steve gold Чемпион! | Победа на турнире
/profile medal list Steve
/profile medal take Steve 1
/profile medal take Steve <UUID медали>
/profile medal take Steve all
```

`list` показывает номера, UUID и путь к файлу. Вместо имени можно указать UUID
игрока. Права прежние: `profiles.admin` либо `f8.admin`.

Изъятая автоматическая медаль **не появится снова** при открытии профиля или новом
завершении созвездия: история заслуги хранится отдельно от владения медалью.
Удаление файла медалей с последующим reload означает изъятие всех медалей этого
игрока. Места изъятых медалей очищаются, остальные предметы коллекции не теряются.

При ручной правке оставляйте UUID существующей медали: изменение её названия,
даты или заслуг не является новой выдачей и не повторяет объявление. Новую выдачу
создаёт новый UUID. Поле `awarded-at` — миллисекунды Unix; без необходимости его
можно не менять. Если редактируете файл, сразу применяйте reload и не выполняйте
параллельно выдачу в тот же файл. Писатель проверяет ожидаемое содержимое перед
заменой и отказывается затирать замеченную внешнюю правку; ошибка попадает в лог.

## Оформление

Основное название всегда жирное, с градиентом от белого к цвету металла.
У серебра конечный цвет стальной с голубым оттенком, поэтому он отличается от белого.

Пример подсказки:

**Астрономия!** — белый → медный градиент

Медная медаль — серая строка непосредственно под названием

— Собрано 1 созвездие.

Получена: 06.09.2026 — серая дата внизу

Между разными заслугами сохранена пустая строка; каждая заслуга начинается с «— ».
Подсказки управления размещаются до даты, дата остаётся последней строкой.
Видимые тексты плагина используют тире. Технические имена, синтаксис YAML, пути,
ключи конфигурации, совместимость старых команд и пользовательский текст не ломаются
ради замены символов. Старый ввод `-` для очистки описания ещё принимается, но в
подсказке теперь предлагается слово `очистить`.

## Сообщения и звук

Стандартный порядок для каждой действительно новой медали:

1. Всем в чат: `Steve получил [Медную медаль]!` — квадратные скобки и их содержимое зелёные.
2. Только получателю одно сообщение: `Вы получили новую медаль! Подробнее /profile.`
3. Только получателю звук `UI_TOAST_CHALLENGE_COMPLETE`.

Звук медали не отправляется миру или соседним игрокам. Обычные звуки других
механик, например награда созвездия, не переписывались. При выдаче самому себе
дополнительное административное подтверждение не добавляет второе личное сообщение.
Если получатель не в сети, объявление, личное сообщение и звук ждут его входа.
Повторный просмотр, reload и миграция старых медалей не создают повторных поздравлений.

Сообщения редактируются в `medals/config.yml`:

```
messages:
  public: '{player} получил <green>[{rarity}]</green>!'
  personal: 'Вы получили новую медаль! Подробнее /profile.'
```

Поддерживается MiniMessage. Доступны `{player}`, `{rarity}`, `{title}`, `{count}`,
`{error}`. Пустая строка отключает соответствующий текст. `rarity` по умолчанию
равна типу металла в нужной форме, например «Медную медаль»; её можно переименовать
в настройках типа. Там же задаётся серая подпись `label` и конечный цвет градиента.
Начало градиента всегда белое. Настройки `astronomy` применяются к новой выдаче и
переносу стандартной награды из 9.3; существующие персональные медали редактируются
в файлах игроков.

Автоматическая медная по прежнему правилу выдаётся только за новое завершение
созвездия, не за старый список завершений. Серебряная и золотая пока выдаются вручную.

## Меню и карточка

* Во втором ряду всех трёх меню больше нет декоративных стёкол. Голова, оценки,
  настройка и нужные стрелки остались. Пустые слоты защищены: положить туда предмет нельзя.
* Карточка расположена рядом с телом, а не над головой. Для обычного игрока высотой
  1,8 блока панель имеет высоту около 1,62 блока.
* Положение зависит от координат двух игроков, но **не от направления прицела**.
  Поэтому можно перевести прицел с игрока на панель — она не отодвигается и не исчезает.
  Между телом и панелью есть небольшой участок удержания фокуса.
* Внизу строка «Последняя медаль:» и настоящий предмет последней полученной медали.
  Название медали не дублируется в основной карточке.
* При наведении на значок появляется отдельная подсказка с жирным градиентным
  названием, типом, заслугами и датой. Прицел можно перевести и на эту подсказку.
  Чтобы не раздувать окно, в нём показаны первые три заслуги; длинные записи
  сокращаются, а полное описание всегда доступно в `/profile`.
* Отпустить Shift, отойти, скрыться за стеной или выйти — карточка закрывается.
  Vanish/невидимость учитываются. Панели видны только своему смотрящему и не занимают actionbar.

## Нагрузка и проверка

Поиск цели работает только для Shift, с прежней частотой 5 раз в секунду.
Текст и оформление не отправляются заново без изменений. Карточка состоит из
трёх лёгких текстовых сущностей, значок добавляется только при наличии медали,
подсказка создаётся только при наведении. Ни реальные пассажиры, ни кликабельные
физические предметы не создаются. Ресурсы для фоновой панели не требуются.

Фоновая запись файлов остаётся последовательной. Миграция и редкая выдача/изъятие
ожидают сохранения; обычная работа карточек не читает файлы и не ищет скины по сети.
Сохранение ожидается при штатном выключении. При аварийном завершении возможна
потеря последних обычных изменений; резервные копии всё равно нужны.

Проверки без Minecraft/Paper сервера: прежние тесты, перенос v1 → v2, отдельные
файлы медалей, изъятие без повторной автонаграды, ручные правки/конфликты записи,
градиенты и подписи, порядок уведомления, геометрия тела/панели/значка/подсказки.
Игровой сервер не запускался; реальный TPS и визуальная точность стандартного
клиентского шрифта остаются для проверки у владельца.
