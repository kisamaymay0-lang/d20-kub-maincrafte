# Обновление 10.31 — Паки префиксов, вода и блоки руками, частицы нот по нотам

Версия плагина: **10.31**. Артефакт сборки: `f8-plugin-10.31`. Ядро: Purpur/Paper **26.2**, Java **25**
(переезд с 1.21.11 описан в [UPDATE-29](UPDATE-29.md)).

Всего в обновлении семь пунктов: новые паки префиксов с сундучками в меню, исправленные частицы нот
медного блока, тихие уведомления о лайках, сообщения за чужие настройки профиля и четыре механики
«шифт + ПКМ» по блоку в руке (вода по меди, вода по кораллам, блок света, рамка ножницами).

## Паки префиксов

Меню «Префиксы» переделано: **средний ряд — сундучки паков** (название пака, сколько кейсов лежит у
игрока, срок ближайшего кейса и что внутри), **верхний и нижний ряды — случайные префиксы** из всего
каталога. Случайный префикс можно надеть, если он у вас уже есть; полный список своих префиксов —
кнопка **«Мои префиксы»** в меню «Настроить».

Пак — это отдельный файл в новой папке:

```text
plugins/f8-plugin/prefixpacks/pref-pack1.yml
```

При первом запуске туда кладётся тестовый пак `pref-pack1` (из комплекта плагина).

| Ключ | Что делает |
| --- | --- |
| `name` | название пака на сундучке |
| `time-hours` | сколько часов живёт кейс с момента выдачи; **-1** — бессрочный |
| `prefixes[].name` | название префикса |
| `prefixes[].file` | иконка из ресурспака: `items/<file>.json` + `textures/item/<file>.png` |
| `prefixes[].color` | необязательно: цвет названия |
| `prefixes[].id` | необязательно: техническое имя (по умолчанию `<пак>_<file>`) |

Префиксы пака — **свои**, а не ссылки на `prefixes.yml`: они добавляются в общий каталог следом за
обычными, поэтому их можно надевать, выдавать и забирать теми же командами. Срок действует на
**кейс**, а не на выпавший префикс: кейс сгорел — и не открыть, а префикс, который из него выпал,
остаётся у игрока.

Команды администратора:

```text
/profile case pack give <ник> pref-pack1 [число]   — выдать кейсы пака
/profile case pack take <ник> pref-pack1 [число]   — забрать кейсы пака
/profile case pack list <ник>                      — сколько кейсов паков у игрока
/profile prefix reload                             — перечитать prefixes.yml и паки
```

## Частицы нот медного блока (исправление)

Раньше на весь шаг проигрывания спавнилась **одна** частица и всегда цветом ноты 0, хотя за шаг
играет до четырёх нот. Теперь **частица на каждую сыгранную ноту и её цветом**: высота звука
переводится в номер ноты ванили (0…24) по формуле `note = 12 + 12·log₂(pitch)` — той самой, по
которой ванильный сервер красит частицу нотного блока. Голоса последовательности (1.2 / 1.0 / 0.79 /
0.63) дают ноты 15 / 12 / 8 / 4 — четыре разных цвета.

## Уведомления в чат

- **Лайк или дизлайк чужому профилю** — владелец видит в чате зелёную («Вам поставили лайк — ник»)
  или красную («Вам поставили дизлайк — ник») строку. Звука нет: сообщение уходит как системное,
  а плагин свои звуки не играет. Работает и из меню профиля, и с карточки в мире.
- **Чужие настройки профиля** теперь отвечают сообщением, а не молчанием: и медали («Медали можно
  расставлять только в своём профиле.»), и описание («Описание можно менять только в своём
  профиле.») — как раньше отвечала кнопка «Настроить».

## Шифт + ПКМ по блоку

| В руке | По чему | Что происходит |
| --- | --- | --- |
| бутылка с водой | медный блок | блок окисляется на одну ступень (`copper` → `exposed` → `watered` → `oxidized`), играют частицы снятия воска, вода уходит — остаётся пустая бутылка |
| бутылка с водой | любой живой коралл | коралл остаётся цветным до следующего ломания, даже вне воды; список в `plugins/f8-plugin/corals.yml` |
| блок света | блок света | уровень падает на 1 (15 → 14 → … → 0), с нуля — снова 15; частиц нет, предмет не тратится |
| ножницы | рамка (Item Frame) | рамка становится невидимой, предмет внутри цел |

Подробности:

- **Медь.** Ступень меняется по приставке имени, а все состояния блока (поворот лестницы, форма
  плиты, открытость двери) сохраняются. Навощённая медь не окисляется — воск для того и нужен.
  Кастомные блоки CraftEngine (медный нотный блок) не трогаются. В креативе вода не расходуется.
- **Кораллы.** Ваниль сушит коралл событием `BlockFadeEvent` — для политых блоков оно отменяется.
  Сломали блок — запись уходит, «навсегда» закончилось. Мёртвые кораллы полить нельзя.
- **Свет.** Крафт: факел в центре, четыре белые стеклянные панели крестом вокруг:

  ```text
    . P .        P — белая панель
    P T P        T — факел
    . P .
  ```

  Выходит блок света уровня 15. Уровень — единственное состояние блока света (0…15), отдельных
  «тусклых» блоков в ванили нет.
- **Рамка.** Повторный шифт + ПКМ ножницами возвращает видимость. Клик (любой) по спрятанной рамке
  выбрасывает предмет наружу и даёт клуб дымки — видно, что рамка изменилась. Пустую спрятанную
  рамку можно сломать как обычно.
