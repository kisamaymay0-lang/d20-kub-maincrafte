# Готовые модели кувшина без «прозрачных» блоков рядом

Проблема: кувшин стоит как нот-блок, то есть как обычный сплошной блок. Minecraft
не рисует грани соседних блоков, которые прижаты к сплошному блоку (оптимизация
— block culling). У модели кувшина по краям есть зазор в 1 пиксель и прозрачные
пиксели текстуры; через них видно эту «вырезанную» грань пола или стены — и
кажется, что блоки рядом стали прозрачными.

Решение в этих файлах: в модель добавлена тонкая плита-подставка по всему
основанию блока (слой 0–0.5 пикселя), которая закрывает зазор и «дырку» в полу.
Ничего больше не изменено — геометрия самого кувшина и текстуры те же.

## Как применить

1. Возьмите файлы из этой папки:
   * `ancient_jug.json`
   * `ancient_jug_filled.json`
2. Положите их в свой ресурспак по адресам:
   * `assets/f8resurs/models/block/ancient_jug.json`
   * `assets/f8resurs/models/block/ancient_jug_filled.json`
3. Пересоберите ZIP, обновите `resource-pack-sha1` и перезайдите в игру.

Ничего в плагине менять не нужно.

## Если хочется иначе

* Плиту можно сделать тоньше/толще или подобрать ей другую текстуру — это
  элемент `from: [0, 0, 0] → to: [16, 0.5, 16]`.
* У плиты намеренно НЕТ `cullface`: иначе её грани тоже скрывались бы рядом с
  соседними блоками и дырка вернулась бы.
* Альтернатива — сменить блок-носитель кувшина на неполный блок (например,
  громоотвод или ступени): тогда соседние блоки вообще перестанут «пропадать».
  Это уже переделка в плагине + перепривязка этих же моделей в паке; скажите —
  сделаю.
