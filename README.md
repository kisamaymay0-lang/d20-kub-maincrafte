# F8 / Adaptation plugin (d20-kub-maincrafte)

Плагин для Paper: чары **Адаптация** и **Бросок I (d20)**, флаконы, тотем
**Отката**, медный нотный блок и меню **F8**.

> ⚠ Этот репозиторий — «боевой» проект с открытыми PR. Описание ниже отражает
> актуальную версию кода в ветке визуального редизайна.

## Возможности

- **Адаптация I–III** (броня): накопление защиты от типа урона, повышенная
  адаптация, перезарядка, босс-бар с таймером;
- **Бросок I** (d20): кубик при ударе, чит-режим `/d20 cheat`, крит-провалы и
  божественное везение;
- **Флаконы**: вода смывает отравление, яд отравляет меч (таймер в action bar);
- **Тотем «Откат I»**: возврат на позицию 5 секунд назад;
- **Медный нотный блок**: собственный инвентарь-«секвенсор» на 4 октавы,
  запуск мелодии сигналом редстоуна;
- Меню **/f8** для выдачи всего этого.

## Сборка

```bash
mvn clean package
# target/adaptation-1.0-SNAPSHOT.jar
```

Зависимости: Paper API (provided). MiniMessage/Adventure предоставляет сам
Paper, поэтому в jar они не упаковываются.

## Настройка цветов и текстов

Все тексты и визуал вынесены в `config.yml` (разделы `messages`, `gui`,
`effects`). Механики живут в `settings`/`rollback` и не меняются настройками
внешнего вида.

### Форматы строк

| Где | Формат | Пример |
|---|---|---|
| `messages.*` (чат, action bar) | MiniMessage | `<gradient:#FFD700:#FF8C00>Текст</gradient>`, `<rainbow>`, `<#FF4444>`, `<click:suggest_command:'/d20 give '>`, `<hover:show_text:'...'>` |
| `gui.*` (названия, рамки, босс-бары) | legacy `&` + HEX | `&l`, `&c`, `&#8AD4FF` |

> В MiniMessage-строках **не используйте** `<` и `>` для обычного текста —
> парсер сочтёт их тегами. Вместо `<игрок>` пишите `«игрок»`.

### Единая палитра (по умолчанию)

```
✔ Успех        <#00FF00>
✖ Ошибка       <#FF4444>
⚠ Предупреждение <#FFAA00>
Инфо           <#8ec5fc>
```

### Пример: перекрасить сообщение и меню

```yaml
messages:
  d20:
    cheat-on: "<gradient:#00FF00:#7CFF7C>✔ Чит-режим активирован! <yellow><bold>[{roll}]</bold></yellow></gradient>"

gui:
  colors:
    enchant: "&#7DF9FF"               # книги в меню F8
    block: "&#FFB85C"                 # блоки
  frames:
    main: GRAY_STAINED_GLASS_PANE     # рамка главного меню
    copper: BLACK_STAINED_GLASS_PANE  # хранилище медного нотного блока
  buttons:
    back-name: "&#C8CFD8Назад"
    close-name: "&#FF6B6BЗакрыть"
  playerlist:
    enabled: true
    format: "<gradient:#9ec5fe:#e0aaff>F8</gradient> <white>»</white> {name}"
```

Плейсхолдеры сообщений: `{seconds}`, `{roll}`, `{time}`, `{item}`, `{player}`,
`{type}`, `{amount}`, `{name}`, `{color}`, `{label}`, `{num}`.

### Отключение эффектов без изменения механик

```yaml
effects:
  particles: true   # все партиклы
  sounds: true      # все звуки
  bossbar: true     # босс-бары адаптации и d20
  actionbar: true   # таймер отравления
```

Даже при `bossbar: false` таймеры адаптации, фазы броска d20 и перезарядки
работают как обычно — игрок просто не видит полосу.

### Заголовки GUI

Заголовки окон (`§8F8`, `§8Новые чарки`, ...) специально не вынесены в конфиг:
код использует их как идентификаторы меню в обработчиках кликов. Изменение
заголовка сломает клики.

## Обновление со старой версии

При выходе нового config.yml старый файл на сервере **не перезаписывается**.
Чтобы получить новые разделы:

1. закройте сервер;
2. удалите `plugins/f8-plugin/config.yml` (инвентари медных блоков хранятся
   отдельно в `blocks.yml` — их удалять не нужно) — при старте создастся
   новый config.yml со всеми разделами;
3. либо скопируйте разделы `messages`, `gui`, `effects` из нового файла в свой.

Пока в конфиге нет раздела `messages`, плагин использует встроенные тексты
(те же, что в новом конфиге по умолчанию).
