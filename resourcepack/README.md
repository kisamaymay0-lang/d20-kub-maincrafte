# Ресурспак плагина f8 (полный, готовый)

Эта папка — **готовый ресурспак**. Не нужно ничего собирать: заархивируй её
целиком (или скачай `f8resurs-resourcepack.zip` из релиза) и положи архив в
папку `resourcepacks` игры. Внутри уже есть всё: `pack.mcmeta`, модели и
текстуры-заглушки, поэтому ничего не будет чёрно-фиолетовым.

## Как установить

1. Скачай готовый `f8resurs-resourcepack.zip` (из релиза или корня репозитория).
2. Положи его в папку `.minecraft/resourcepacks` (не распаковывая).
3. В игре: Настройки → Пакеты ресурсов → включи пакет `f8resurs`.
4. Если пакет уже был включён — нажми `F3 + T`, чтобы перезагрузить текстуры.

> Для Minecraft 1.21.11 (Paper 1.21.11). Если игра пишет «пакет для другой
> версии» — это ок, можно нажать «Да» и продолжить.

## Что внутри и как это устроено

Плагин назначает предметам модель через компонент `item_model` (система
1.21.4+). Поэтому модель предмета лежит в **двух** местах:

- `assets/f8resurs/items/<имя>.json` — «указатель» на модель
  (содержит `"type": "minecraft:model", "model": "f8resurs:item/<имя>"`);
- `assets/f8resurs/models/item/<имя>.json` — сама модель
  (`item/generated` + текстура `layer0`).

Если раньше модели не работали — почти наверняка не хватало папки `items/`.

## Куда класть свои текстуры (PNG)

Все картинки лежат в `assets/f8resurs/textures/`. Замени заглушки на свои,
сохранив **точные имена файлов** (регистр важен):

| Предмет | Файл текстуры (замени) |
| --- | --- |
| Медный нотный блок (блок) | `assets/f8resurs/textures/block/copper_note_block.png` |
| Красная икра | `assets/f8resurs/textures/item/red_caviar.png` |
| Чёрная икра | `assets/f8resurs/textures/item/black_caviar.png` |
| Опустошённая треска | `assets/f8resurs/textures/item/empty_cod.png` |
| Опустошённый лосось | `assets/f8resurs/textures/item/empty_salmon.png` |
| Бутерброд с красной икрой | `assets/f8resurs/textures/item/caviar_sandwich_red.png` |
| Бутерброд с чёрной икрой | `assets/f8resurs/textures/item/caviar_sandwich_black.png` |
| Флакон с водой | `assets/f8resurs/textures/item/flask_water.png` |
| Флакон с отравлением | `assets/f8resurs/textures/item/flask_poison.png` |
| Особая звезда (созвездия) | `assets/f8resurs/textures/item/star.png` |

Заглушки сейчас — цветные квадратики (чтобы сразу было видно, что пакет
работает). Замени их на свои текстуры и перезагрузи пакет (`F3 + T`).

## Особая звезда (созвездия)

- Модель: `f8resurs:star`. Текстура уже есть: `assets/f8resurs/textures/item/star.png`
  (жёлтая звезда на прозрачном фоне, 32×32). Её можно заменить на свою.
- Звезда отображается плашмя (billboard), поэтому нужна квадратная PNG
  с прозрачным фоном.
- Чтобы сделать несколько видов звёзд (например, другого цвета для разных
  созвездий), добавь ещё пару файлов:
  - `assets/f8resurs/items/star_red.json` и `assets/f8resurs/models/item/star_red.json`
    (скопируй `star.json`, поменяй в тексте `star` → `star_red`),
  - текстуру `assets/f8resurs/textures/item/star_red.png`,
  - и укажи модель в файле созвездия (`star-model`) или командой
    `/stars model <созвездие> f8resurs:star_red`.
- Линии между звёздами рисуются обычным блоком (стержень Энда) — текстура не нужна.

## Пространство имён

- Пространство имён — `f8resurs`. Не меняй его: плагин обращается именно к нему.
- Имена файлов моделей и текстур должны совпадать **точно** (регистр важен).
