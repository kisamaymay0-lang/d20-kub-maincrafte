# Ресурспак плагина f8 (полный, готовый)

Эта папка — **готовый ресурспак**. Не нужно ничего собирать: заархивируй её
целиком (или скачай `f8resurs-resourcepack.zip` из релиза) и положи архив в
папку `resourcepacks` игры. Внутри уже есть всё: `pack.mcmeta`, модели и
текстуры-заглушки, поэтому ничего не будет чёрно-фиолетовым.

## Как пак попадает к игрокам

Есть ровно один архив `f8resurs-resourcepack.zip` — он лежит в корне репозитория
и прикладывается к релизу. Свой HTTP-сервер плагин **не** запускает: скачивание
делает сам Minecraft (клиент), как для любого серверного ресурспака.

**Способ 1 — сервер предлагает пак сам (нужен один раз настроить ссылку).**

1. Опубликуйте релиз (например, `git tag v10.2 && git push origin v10.2`). CI
   создаёт релиз и прикладывает к нему `f8resurs-resourcepack.zip`.
2. В `plugins/f8-plugin/config.yml` оставьте стандартную ссылку
   `resource-pack.url: https://github.com/kisamaymay0-lang/d20-kub-maincrafte/releases/latest/download/f8resurs-resourcepack.zip`
   или впишите свою. Внизу этой страницы описано, чего не надо делать.
3. Перезапустите сервер. В логе появится строка
   `Ресурспак готов к раздаче: ... (SHA-1 ...)`, а игроки при входе увидят
   предложение скачать пак.

**Способ 2 — вручную.** Скачай `f8resurs-resourcepack.zip`, положи в
`.minecraft/resourcepacks` (не распаковывая), включи в Настройки → Пакеты
ресурсов, нажми `F3 + T`.

Ставьте только один из способов. Если игрок держит архив и в `resourcepacks`,
и получает серверный — клиент всё равно возьмёт серверный (он выше по приоритету),
но качать один и тот же файл дважды смысла нет.

> Пакета хватает на всех: цветные иконки, кувшин, изморозь, медали, префиксы.
> Требуется Minecraft 1.21.11 (Paper 1.21.11). Если игра пишет «пакет для другой
> версии» — нажмите «Да» и продолжайте, либо пропустите предложение.

## Что внутри и как это устроено

Плагин назначает предметам модель через компонент `item_model` (система
1.21.4+). Поэтому модель предмета лежит в **двух** местах:

- `assets/f8resurs/items/<имя>.json` — «указатель» на модель
  (содержит `"type": "minecraft:model", "model": "f8resurs:item/<имя>"`);
- `assets/f8resurs/models/item/<имя>.json` — сама модель
  (`item/generated` + текстура `layer0`).

Если раньше модели не работали — почти наверняка не хватало папки `items/`.

## Куда класть свои текстуры (PNG)

Все картинки лежат в `assets/f8resurs/textures/`. Замени заглушки на свои,
сохранив **точные имена файлов** (регистр важен):

| Предмет | Файл текстуры (замени) |
| --- | --- |
| Медный нотный блок (блок) | `assets/f8resurs/textures/block/copper_note_block.png` |
| Древний кувшин (блок и предмет) | `assets/f8resurs/textures/block/gor4ok.png` (лист 40x40; собирается скриптом) |
| Красная икра | `assets/f8resurs/textures/item/red_caviar.png` |
| Чёрная икра | `assets/f8resurs/textures/item/black_caviar.png` |
| Опустошённая треска | `assets/f8resurs/textures/item/empty_cod.png` |
| Опустошённый лосось | `assets/f8resurs/textures/item/empty_salmon.png` |
| Бутерброд с красной икрой | `assets/f8resurs/textures/item/caviar_sandwich_red.png` |
| Бутерброд с чёрной икрой | `assets/f8resurs/textures/item/caviar_sandwich_black.png` |
| Флакон с водой | `assets/f8resurs/textures/item/flask_water.png` |
| Флакон с отравлением | `assets/f8resurs/textures/item/flask_poison.png` |
| Особая звезда (созвездия) | `assets/f8resurs/textures/item/star.png` |
| Сплошной луч | `assets/f8resurs/textures/item/star_beam.png` |
| Пунктирный предварительный луч | `assets/f8resurs/textures/item/star_beam_preview.png` |

Заглушки сейчас — цветные квадратики (чтобы сразу было видно, что пакет
работает). Замени их на свои текстуры и перезагрузи пакет (`F3 + T`).

## Особая звезда (созвездия)

- Модель: `f8resurs:star`. Текстура уже есть: `assets/f8resurs/textures/item/star.png`
  (жёлтая звезда на прозрачном фоне, 32×32). Её можно заменить на свою.
- Звезда — плоская картинка, отдельно развёрнутая к наблюдателю, поэтому
  нужна квадратная PNG с прозрачным фоном. В плагине 9.0 её смещение больше
  не вращается вместе с камерой (используется `Billboard.FIXED`).
- Чтобы сделать несколько видов звёзд (например, другого цвета для разных
  созвездий), добавь ещё пару файлов:
  - `assets/f8resurs/items/star_red.json` и `assets/f8resurs/models/item/star_red.json`
    (скопируй `star.json`, поменяй в тексте `star` → `star_red`),
  - текстуру `assets/f8resurs/textures/item/star_red.png`,
  - и укажи модель в файле созвездия (`star-model`) или командой
    `/stars model <созвездие> f8resurs:star_red`.
- В 9.1 линии рисуются плоскими ItemDisplay-полосами: модели `f8resurs:star_beam`
  и `f8resurs:star_beam_preview`. У превью пунктирная прозрачная текстура; обе
  модели без затенения граней (`shade: false`, `ambientocclusion: false`) и с
  постоянным освещением. Не заменяйте их на `item/generated`/стержень Энда:
  это вернёт лишнюю геометрию и затенение.

## Пространство имён

- Пространство имён — `f8resurs`. Не меняй его: плагин обращается именно к нему.
- Имена файлов моделей и текстур должны совпадать **точно** (регистр важен).

## Поставленный медный блок (исправление в 9.0)

В `assets/minecraft/blockstates/note_block.json` перечислены 25 непересекающихся
вариантов: `note=0..23` используют обычную модель, `note=24` — медную. Нельзя
возвращать вариант `""` рядом с `"note=24"`: оба правила применяются к одному
состоянию, из-за чего текстура поставленного блока не выбиралась правильно.
Свойства `instrument` и `powered` не влияют на выбор модели. Нота 24 по-прежнему
зарезервирована плагином для медного блока.

После обновления нужно заменить ZIP в игре и нажать `F3 + T`. Если свои PNG
уже нарисованы, сохраните их, обновив только указанный файл blockstates.
Другой ресурспак с более высоким приоритетом не должен переопределять этот файл.

## Пересборка и проверка

```
python3 scripts/build_resourcepack.py        # пересобрать ZIP из resourcepack/
python3 scripts/build_resourcepack.py --check  # проверить, что ZIP совпадает с папкой
python3 scripts/test_jug.py                  # проверки кувшина, нот-блока и раздачи пака
python3 scripts/preview_models.py            # оффлайн-картинки моделей (artifacts/preview/)
```

Текстура и модели кувшина — не «руками нарисованные» файлы, а результат двух
генераторов (исходный рисунок владельца лежит в `scripts/jug_texture_source.png`
и не меняется):

```
python3 scripts/build_jug_texture.py   # лист block/gor4ok.png: терракота, зев, жидкость
python3 scripts/build_jug_models.py    # модели кувшина и предметные ссылки
```

## Обновление до 9.1

Обновите **JAR и ZIP вместе**: старый пакет не содержит моделей новых лучей.
Для собственного пакета добавьте все 6 файлов `star_beam`/`star_beam_preview`
из папок `items`, `models/item` и `textures/item`; существующие PNG звёзд,
еды, флаконов и медного блока можно оставить своими. Текстуры служебных лучей
используют RGBA PNG (пунктир содержит настоящие прозрачные промежутки).

Вращение звезды делает плагин, менять `star.png` не нужно. Скорость по умолчанию
4°/секунду, один оборот за 90 секунд. Подробности: `docs/UPDATE-9.1.md` в репозитории.


## Медали профиля (9.3)

Добавлены пиксельные модели `f8resurs:medal_copper`, `f8resurs:medal_silver` и
`f8resurs:medal_gold`. Золотая также служит кнопкой «Настроить медали».
Головы в `/profile` используют настоящие скины игроков, для них отдельный PNG не нужен.

Для своего пакета скопируйте по три новых файла из `items/`, `models/item/` и
`textures/item/` (девять файлов всего) в пространстве `assets/f8resurs/`.
Остальные PNG менять не требуется. Формат пакета не изменился.

`scripts/draw_medals.py` содержит исходный пиксельный рисунок. Это ручной инструмент:
обычная сборка его не запускает и не перерисовывает ваши заменённые PNG.

## Префиксы профиля: глифы перед ником

Иконка префикса перед ником (чат, tab, над головой, профиль) — это глифы
шрифта `assets/f8resurs/font/profile_ui.json`: `\uE101`–`\uE105` — лайки и
медали, `\uE106`–`\uE10F` — картинки префиксов `pref1`–`pref10` из
`assets/f8resurs/textures/item/`. Картинки-глифы рисуются 1:1 (шрифт 8 px),
поэтому рисуйте их компактно и контрастно.

Если вместо иконки перед ником виден **квадрат** — клиент загрузил старый
архив (в нём нет `\uE106`–`\uE10F`). Замените ZIP на свежий из корня
репозитория и нажмите `F3 + T`. Свежий архив легко проверить:
`python3 scripts/build_resourcepack.py --check`. Если пак раздаётся по ссылке,
опубликуйте релиз с новым архивом: ссылка `releases/latest/download` подхватит его сама.

Для своих префиксов кладите PNG рядом с `pref1.png`…`pref10.png`, сохраняя
имена файлов — плагин ссылается на `prefN` по номерам из `prefixes.yml`.
