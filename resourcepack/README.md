# Ресурспак для плагина f8

В этой папке лежат **готовые файлы моделей** — их нужно скопировать в свой ресурспак
(они уже в правильной структуре: `assets/...`).

Модели уже настроены на текстуры по этим путям. Тебе остаётся только **добавить
сами картинки (PNG)** с указанными именами:

| Предмет | Файл текстуры (положить сюда) |
| --- | --- |
| Медный нотный блок (поставленный и в руке) | `assets/f8resurs/textures/block/copper_note_block.png` |
| Красная икра | `assets/f8resurs/textures/item/red_caviar.png` |
| Чёрная икра | `assets/f8resurs/textures/item/black_caviar.png` |
| Опустошённая треска | `assets/f8resurs/textures/item/empty_cod.png` |
| Опустошённый лосось | `assets/f8resurs/textures/item/empty_salmon.png` |
| Бутерброд с красной икрой | `assets/f8resurs/textures/item/caviar_sandwich_red.png` |
| Бутерброд с чёрной икрой | `assets/f8resurs/textures/item/caviar_sandwich_black.png` |
| Особая звезда (созвездия) | `assets/f8resurs/textures/item/star.png` |

> Текстура медного нотного блока — **блочная** (16x16 или больше, квадратная),
> как обычная текстура блока. Остальные — предметные (по образцу флаконов).

## Как это работает (для понимания)

- **Медный нотный блок** — это обычный `note_block`, помеченный нотой №24.
  В `assets/minecraft/blockstates/note_block.json` добавлен вариант `note=24`,
  который показывает твою текстуру **только** у медных нотных блоков.
  Обычные нотные блоки при этом не меняются.
- Остальные предметы используют модель `item/generated` с одной текстурой `layer0`,
  как флаконы (поэтому флаконы у тебя и работают).

## Важно

- Пространство имён — `f8resurs` (как у флаконов). Не меняй его.
- Имена файлов моделей и текстур должны совпадать **точно** (регистр важен).
- После добавления файлов в ресурспак обнови его на сервере и перезайди в игру (F3+T).

## Особая звезда (созвездия)

- Текстура звезды: `assets/f8resurs/textures/item/star.png` (модель `f8resurs:star`
  уже добавлена). Звезда отображается плоской (billboard), поэтому подойдёт
  квадратная PNG со звездой (можно с прозрачным фоном).
- Если хочешь несколько видов звёзд (например, разного цвета для разных созвездий),
  добавь ещё модели (например `f8resurs:star_red`) и укажи их в файле созвездия
  через `star-model` или командой `/stars model <созвездие> <model>`.
- Линии между звёздами рисуются обычным ванильным блоком (стержень Энда) —
  текстура для них не нужна.
