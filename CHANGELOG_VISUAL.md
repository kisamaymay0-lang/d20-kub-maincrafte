## 2. Новый класс `MessageUtils.java`

Единая точка работы с текстом и эффектами (все методы только визуальные):

- `send(sender, "ключ", "{токен}", значение)` — сообщение в чат через MiniMessage
  (работает и для консоли);
- `action(player, "ключ", ...)` — action bar;
- `legacy("&c текст &#FF4444HEX")` — перевод в legacy-формат `§` для названий
  предметов, заголовков босс-баров и рамок GUI;
- `particles() / sounds() / bossBars() / actionBars()` — чтение `effects.*`;
- Встроенные fallback-тексты: если на сервере остался **старый config.yml**
  без раздела `messages`, плагин использует те же тексты (в новых цветах).

Единая палитра сообщений:
`✔ Успех <#00FF00>` · `✖ Ошибка <#FF4444>` · `⚠ Предупреждение <#FFAA00>` · инфо `<#8ec5fc>`.

## 3. config.yml

- Секция `settings` и `rollback` — **без изменений** (механики).
- Добавлена секция `messages` — все тексты чата/action bar (MiniMessage).
- Добавлена секция `gui` — рамки окон, кнопки «Назад/Закрыть», палитра цветов,
  подписи/цвета босс-баров, префикс в табе.
- Добавлена секция `effects` — глобальные вкл/выкл: `particles`, `sounds`,
  `bossbar`, `actionbar` (механика при выключении продолжает работать).

## 4. Сообщения (40+ мест)

Все `player.sendMessage(ChatColor.RED + ...)` и `sendActionBar("§7...")` заменены
на `MessageUtils.*` с ключами `messages.*`:

- адаптация: разбита / закончилась / перезарядка готова;
- d20: usage (кликабельные примеры команд), чит-режим, enchant, give, отмена
  баффа, «время истекло», крит-провал (1), божественное везение (20);
- флаконы: все ответы команды `/flask`, таймер отравления в action bar;
- rollback: все ответы команды `/rollback`;
- меню F8: уведомление о выдаче предмета (`messages.menu.given`).

## 5. GUI F8 — новый визуал (логика кликов/ПДК не менялась)

- Рамки из стеклянных панелей по периметру окон (материал — `gui.frames.*`);
- Единые кнопки: **«Назад»** (стрелка) и **«Закрыть»** (барьер)
  (`gui.buttons.*`, оранжево-красный HEX);
- Названия и лор предметов переведены на HEX-палитру `gui.colors.*`,
  лор отформатирован столбцами («▸»);
- При открытии меню — частицы + мягкий звук (`gui.open-effect`, поверх `effects.*`);
- Заголовки окон (`§8F8`, `§8Новые чарки` ...) **намеренно не вынесены в конфиг**:
  по ним плагин определяет открытое меню в обработчике кликов;
- Хранилище медного нотного блока: слоты-разделители тоже берут материал из
  конфига (`gui.frames.copper`), набор блокированных слотов не менялся.

## 6. Визуальная обратная связь

- **Партиклы/звуки/босс-бары адаптации и d20** можно отключить через `effects.*`
  — таймеры, урон и фазы броска продолжают работать;
- Заголовки босс-баров теперь с HEX-цветами типов урона и собираются из
  шаблонов `gui.bossbar.*` (раньше были «зашиты» `§c§l...`);
- **Градиентный префикс в табе** (список игроков по Tab): включается в
  `gui.playerlist.enabled`, формат — MiniMessage с градиентом.
  Это НЕ трогает чат/наментеги/тимы (ими управляют другие плагины).
